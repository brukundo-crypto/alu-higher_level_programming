# alu-higher_level_programming

Higher level programming projects at African Leadership University, written
in Python 3.8 on Ubuntu 20.04.

This repository holds the work for the Python track: scripting basics,
data structures, object-oriented programming, exceptions, file handling and
database access. Each project lives in its own directory with a README
describing what it covers.

All Python files start with `#!/usr/bin/python3`, are executable, and follow
the pycodestyle style guide.
