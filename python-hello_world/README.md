# Python - Hello, World

First Python project. Covers running Python from the shell, printing text and
variables, string indexing and slicing, and f-strings.

## What is in here

| File | Description |
|---|---|
| 0-run | Shell script that runs a Python file named in `$PYFILE` |
| 1-run_inline | Shell script that runs Python code held in `$PYCODE` |
| 2-print.py | Prints a string containing a double quote |
| 3-print_number.py | Prints an integer with an f-string, without casting it |
| 4-print_float.py | Prints a float to two decimal places |
| 5-print_string.py | Repeats a string and slices its first 9 characters |
| 6-concat.py | Joins two strings into one sentence |
| 7-edges.py | Slices the first 3, last 2 and middle of a word |
| 8-concat_edges.py | Builds a new sentence from slices, with no string literals |
| 9-easter_egg.py | Prints the Zen of Python |

## Requirements

- Ubuntu 20.04 LTS, Python 3.8.5
- Python files begin with `#!/usr/bin/python3`
- Shell scripts begin with `#!/bin/bash` and are exactly two lines long
- All files are executable and end with a new line
- Python code follows pycodestyle 2.7
