# Python - More Data Structures: Set, Dictionary

Functions covering Python sets, dictionaries, matrices and map, written
without importing any module.

## What is in here

| File | Description |
|---|---|
| 0-square_matrix_simple.py | Squares every value of a matrix into a new matrix |
| 1-search_replace.py | Replaces every occurrence of an element in a new list |
| 2-uniq_add.py | Adds all unique integers of a list |
| 3-common_elements.py | Returns the elements two sets have in common |
| 4-only_diff_elements.py | Returns the elements present in only one of two sets |
| 5-number_keys.py | Returns how many keys a dictionary has |
| 6-print_sorted_dictionary.py | Prints a dictionary by alphabetically ordered keys |
| 7-update_dictionary.py | Replaces or adds a key and value in a dictionary |
| 8-simple_delete.py | Deletes a key from a dictionary if it exists |
| 9-multiply_by_2.py | Returns a new dictionary with every value doubled |
| 10-best_score.py | Returns the key holding the biggest value |
| 11-multiply_list_map.py | Multiplies every value of a list using map, no loops |
| 12-roman_to_int.py | Converts a Roman numeral string to an integer |

## Requirements

- Ubuntu 20.04 LTS, Python 3.8.5
- Files begin with `#!/usr/bin/python3` and end with a new line
- All files are executable
- Code follows pycodestyle 2.7
- No modules are imported anywhere in this directory
