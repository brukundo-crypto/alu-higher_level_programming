# Python - Data Structures: Lists, Tuples

Functions covering Python lists, tuples, indexing, slicing and sequence
operations, written without importing any module.

## What is in here

| File | Description |
|---|---|
| 0-print_list_integer.py | Prints all integers of a list, one per line |
| 1-element_at.py | Retrieves an element from a list, returning None if out of range |
| 2-replace_in_list.py | Replaces an element at a position, modifying the original list |
| 3-print_reversed_list_integer.py | Prints all integers of a list in reverse order |
| 4-new_in_list.py | Replaces an element in a copy, leaving the original untouched |
| 5-no_c.py | Removes every c and C from a string without using str.replace() |
| 6-print_matrix_integer.py | Prints a matrix of integers, one row per line |
| 7-add_tuple.py | Adds two tuples, padding with 0 and ignoring anything past the first two |
| 8-multiple_returns.py | Returns a tuple of a string's length and its first character |
| 9-max_integer.py | Finds the biggest integer of a list without using max() |
| 10-divisible_by_2.py | Returns a list of booleans marking the multiples of 2 |
| 11-delete_at.py | Deletes the item at a position without using pop() |
| 12-switch.py | Switches the values of two variables in one line |

## Requirements

- Ubuntu 20.04 LTS, Python 3.8.5
- Files begin with `#!/usr/bin/python3` and end with a new line
- All files are executable
- Code follows pycodestyle 2.7
- No modules are imported anywhere in this directory
