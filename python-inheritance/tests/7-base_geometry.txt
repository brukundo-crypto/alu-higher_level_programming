The ``7-base_geometry`` module
==============================

Using ``BaseGeometry``
----------------------

Import the class and build an instance:

    >>> BaseGeometry = __import__('7-base_geometry').BaseGeometry
    >>> bg = BaseGeometry()

``area`` is not implemented at this level:

    >>> bg.area()
    Traceback (most recent call last):
    Exception: area() is not implemented

``integer_validator`` stays silent for a positive integer:

    >>> bg.integer_validator("my_int", 12)
    >>> bg.integer_validator("width", 89)
    >>> bg.integer_validator("age", 1)

It returns nothing:

    >>> print(bg.integer_validator("size", 7))
    None

A value that is not an integer raises a TypeError, and the name given is
used in the message:

    >>> bg.integer_validator("name", "John")
    Traceback (most recent call last):
    TypeError: name must be an integer

    >>> bg.integer_validator("age", 4.5)
    Traceback (most recent call last):
    TypeError: age must be an integer

    >>> bg.integer_validator("width", None)
    Traceback (most recent call last):
    TypeError: width must be an integer

    >>> bg.integer_validator("height", (4,))
    Traceback (most recent call last):
    TypeError: height must be an integer

    >>> bg.integer_validator("size", [3])
    Traceback (most recent call last):
    TypeError: size must be an integer

    >>> bg.integer_validator("value", {3, 4})
    Traceback (most recent call last):
    TypeError: value must be an integer

    >>> bg.integer_validator("number", "12")
    Traceback (most recent call last):
    TypeError: number must be an integer

A boolean is rejected too, even though bool inherits from int:

    >>> bg.integer_validator("flag", True)
    Traceback (most recent call last):
    TypeError: flag must be an integer

Zero and negative numbers raise a ValueError:

    >>> bg.integer_validator("age", 0)
    Traceback (most recent call last):
    ValueError: age must be greater than 0

    >>> bg.integer_validator("distance", -4)
    Traceback (most recent call last):
    ValueError: distance must be greater than 0

The type is checked before the value, so something that is both the wrong
type and negative raises the TypeError:

    >>> bg.integer_validator("temperature", -2.5)
    Traceback (most recent call last):
    TypeError: temperature must be an integer

The smallest accepted value is 1:

    >>> bg.integer_validator("minimum", 1)

Both arguments are required. Calling ``integer_validator()`` with no
argument raises a TypeError:

    >>> bg.integer_validator()  # doctest: +IGNORE_EXCEPTION_DETAIL
    Traceback (most recent call last):
    TypeError

Calling ``integer_validator("age")`` with only the name raises a TypeError
as well:

    >>> bg.integer_validator("age")  # doctest: +IGNORE_EXCEPTION_DETAIL
    Traceback (most recent call last):
    TypeError
