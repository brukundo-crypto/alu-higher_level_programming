The ``1-my_list`` module
========================

Using ``MyList``
----------------

Import the class:

    >>> MyList = __import__('1-my_list').MyList

``MyList`` is a subclass of ``list``, so it behaves like one:

    >>> issubclass(MyList, list)
    True

A new list starts empty:

    >>> my_list = MyList()
    >>> print(my_list)
    []

``print_sorted`` prints the elements in ascending order:

    >>> my_list = MyList([1, 4, 2, 3, 5])
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

The original list is left untouched:

    >>> print(my_list)
    [1, 4, 2, 3, 5]

It works after appending:

    >>> my_list = MyList()
    >>> my_list.append(7)
    >>> my_list.append(1)
    >>> my_list.append(9)
    >>> my_list.print_sorted()
    [1, 7, 9]

An empty list prints an empty list:

    >>> MyList().print_sorted()
    []

A list already in order is unchanged:

    >>> MyList([1, 2, 3]).print_sorted()
    [1, 2, 3]

Negative numbers sort correctly:

    >>> MyList([5, -2, 0, -9, 3]).print_sorted()
    [-9, -2, 0, 3, 5]

Repeated values are all kept:

    >>> MyList([4, 4, 2, 2]).print_sorted()
    [2, 2, 4, 4]

A single element is fine:

    >>> MyList([42]).print_sorted()
    [42]

``print_sorted`` returns nothing, it only prints:

    >>> print(MyList([2, 1]).print_sorted())
    [1, 2]
    None

Ordinary list methods still work:

    >>> my_list = MyList([1, 2, 3])
    >>> len(my_list)
    3
    >>> my_list.pop()
    3
    >>> my_list.print_sorted()
    [1, 2]
